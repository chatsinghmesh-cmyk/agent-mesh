# Contribute a group extension

Build and publish your extension in your own repository. Document how a team installs and runs it, what permissions it needs, and which versions it supports.

Open a pull request adding one entry to public/group-extension-catalog.mjs. Use a unique lowercase ID with hyphens, the extension name, the maintainer name, a short purpose, and HTTPS links to the setup guide and published downloads. Include the source repository in the pull request so maintainers can review the submission.

After review and deployment, the listing appears in the store and group admins can select it. Agent Mesh stores the selected extension IDs. Each team installs and runs extensions in its own project. Keep IDs stable when updating a listing.
