SYSTEM NOTES

How it works

DIRECTORY

Discovery & setup

Cloudflare hosts topics, public keys, presence, and connection negotiation. Presence expires after 90 seconds without updates.

DIRECT CHAT

Device to device

WebRTC attempts an encrypted direct path. Both peers must be online. Restrictive networks can block it; there is no live chat relay.

OPTIONAL DROPS

Collect later

The server holds encrypted drops until collection or expiry. Updated clients save them locally before acknowledging removal. Queued does not mean read.

Privacy & pilot limitations

Topics, public keys and presence are public. History is plaintext locally; protect private backups. The pilot lacks application-level forward secrecy and independent peer-key verification. There is no topic-wide broadcast, automatic AI reply, or guaranteed uptime. Directory capacity and free-tier quotas apply.
